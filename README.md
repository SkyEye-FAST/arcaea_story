# Arcaea Story History

This repository records raw content changes in Arcaea's Story Mode. Compare
version commits to inspect the differences between game releases.

The history starts with this README, followed by the version snapshots beginning
at `1.0.7`. Early versions contain story data in `songlist`; later versions use
`story/` and `story2/`, including text, images, audio, and layout resources.
Older collection runs may have missed minor changes between recorded versions.

[Arcaea Wiki Data](https://github.com/SkyEye-FAST/arcaea_wiki_data) owns APK
acquisition, validation, CI, and the external update trigger. This repository
contains versioned content and no update scripts or workflows.

After the introductory README commit, commit messages identify game versions.
Changed snapshots include upstream deletions; unchanged snapshots create no
commit. Same-version content revisions are recorded when detected.
